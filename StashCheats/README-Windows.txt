Stash cheat codes for GTA: Vice City (Windows)
==============================================

Adds two cheat codes to Vice City. Type them while playing, like the game's own cheats:

  IMMORTAL   Unlimited health and armour. The car you're in can't be wrecked either.
  NOCOPS     The police never chase you. Your wanted level stays at zero.

Type a code again to turn it off. A message in the top-left corner confirms each one.

Needs the original version 1.0 of the game (gta-vc.exe, 3,088,896 bytes). On any other version,
including the current Steam release, the cheats do nothing and the game runs normally.


Install
-------
1. Open the folder that contains gta-vc.exe.
2. Copy everything from this zip into it: dinput8.dll and the scripts folder.
   If Windows asks, merge the scripts folder with the one already there.
3. Start the game and type a code.

Already have the widescreen fix or another mod loader? Copy just scripts\StashCheatsVC.asi.

Remove
------
Delete scripts\StashCheatsVC.asi (and dinput8.dll if you copied it).


What's inside
-------------
scripts\StashCheatsVC.asi   The cheat codes. Source: https://github.com/shivvyas2/Stash/tree/main/StashCheats
dinput8.dll                  Ultimate ASI Loader by ThirteenAG (MIT licence, see LICENSE-UltimateASILoader.txt).
                             It makes the game load mods from the scripts folder.

Windows may warn about these files because they aren't signed. That's normal for game mods.
